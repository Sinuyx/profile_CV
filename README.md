# Cybersecurity Portfolio — GitHub Pages

A responsive bilingual (English/Vietnamese) static portfolio with a cybersecurity dark theme.

## Included
- `index.html` — page structure and project links
- `styles.css` — responsive dark UI
- `script.js` — EN/VI language switcher, mobile navigation, active section tracking
- `assets/CV.pdf` — placeholder file; replace with your actual CV PDF

## Before publishing
1. Open `index.html` and replace `Truong` with your preferred display name if needed.
2. Replace `[Add your email]`, `YOUR_EMAIL@example.com`, `[Add your LinkedIn URL]`, and `[Add year]`.
3. Replace `assets/CV.pdf` with your real CV PDF (keep the exact filename `CV.pdf`), or update the link in `index.html`.
4. Review project descriptions so they accurately describe your own contribution, especially for team projects.
5. Check skills and remove anything you have not personally practiced.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `portfolio`.
2. Upload all files and folders from this ZIP to the repository root (the `index.html` file should be at the root).
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for deployment. Your website URL will look like `https://YOUR_USERNAME.github.io/portfolio/`.

For a user-site repository named `YOUR_USERNAME.github.io`, the URL is `https://YOUR_USERNAME.github.io/`.

## Notes
- No build step or package installation is required.
- Google Fonts are loaded from Google Fonts; the site still falls back to system fonts if unavailable.
- The skill bars are illustrative only, not validated proficiency scores. You may remove them if you prefer not to imply measured proficiency.
